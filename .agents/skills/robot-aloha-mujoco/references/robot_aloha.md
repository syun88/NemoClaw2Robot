# robot_aloha

## Robot Contract

- Robot name: `aloha`
- Simulator: MuJoCo MJCF generated by `nemoclaw2robot.scene`
- Base robot model: official Google DeepMind MuJoCo Menagerie ALOHA 2 MJCF at `external/mujoco_menagerie/aloha/`
- Coordinate frame: x forward, y left, z up
- Default active arm: right arm unless the prompt says left or right explicitly
- Default object: red cube on the table; if the prompt asks for `sphere`, `ball`, `球体`, `球`, or `ボール`, the generated object geom is a sphere.
- Default target: blue target pad on the table

## Prompt Mapping

Map Japanese and English prompts conservatively:

- Words like `掴`, `つか`, `grab`, `grasp`, `pick` map to `grasp`.
- Words like `置`, `移動`, `place`, `put`, `move` map to `place` when a target is implied.
- Words like `押`, `push`, `slide` map to `push`.
- Words like `確認`, `観察`, `inspect`, `observe` map to `inspect`.
- Words like `sphere`, `ball`, `球体`, `球`, `ボール` map to object `sphere`.

If the prompt is ambiguous but mentions ALOHA and a cube, choose `grasp`.

## Scene Contents

The generated scene contains:

- The official ALOHA 2 robot, table, frame, and cameras from MuJoCo Menagerie.
- A free-joint manipulation object. It is a cube by default and a sphere when requested by the prompt.
- A target pad and push-lane marker.

The generated `scene.xml` expands the official MJCF and adds task objects without editing the upstream submodule.
The host installer uploads `external/mujoco_menagerie/aloha/` into the sandbox runtime.

## Runtime Commands

Preferred OpenClaw tool call:

```json
{
  "tool": "aloha_mujoco_run",
  "arguments": {
    "prompt": "Alohaのアームロボットでキューブを掴んでください",
    "simulate": true,
    "strict_sim": true
  }
}
```

Preferred live-viewer tool call when the user asks to watch in real time:

```json
{
  "tool": "aloha_mujoco_live",
  "arguments": {
    "prompt": "リアルタイムでAlohaのアームロボットが球体を掴むところを見たい"
  }
}
```

If the agent only exposes `tool_search_code`, use:

```javascript
return await openclaw.tools.call("aloha_mujoco_run", {
  prompt: "Alohaのアームロボットでキューブを掴んでください",
  simulate: true,
  strict_sim: true
});
```

For a live viewer request through `tool_search_code`, use:

```javascript
return await openclaw.tools.call("aloha_mujoco_live", {
  prompt: "リアルタイムでAlohaのアームロボットが球体を掴むところを見たい"

```

Do not use `openclaw.tools.readSkill`, `openclaw.tools.runSkill`, or `openclaw.skills.spawn`; those APIs are not available in the OpenClaw compact tool bridge.

## Output Artifacts

Each run directory contains:

- `plan.json`: normalized robot task.
- `scene.xml`: generated MJCF.
- `trajectory.json`: generated only when MuJoCo simulation runs.
- `summary.md`: human-readable run summary.

## Safety and Scope

- Never modify the `NemoClaw/` submodule.
- Never modify the `external/mujoco_menagerie/` submodule.
- Do not claim physical robot execution; this skill targets simulation.
- Treat the current controller as a scripted MuJoCo scaffold, not a learned manipulation policy.
- The first controller opens and closes the official ALOHA gripper joints, but cube lift/transfer still uses a scripted attachment after the close phase rather than a fully learned or contact-only grasp policy.
- When MuJoCo is missing, produce plan and scene artifacts and state that simulation was not executed.
